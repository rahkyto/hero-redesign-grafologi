# hero-redesign-grafologi
Proyek ini adalah hasil redesign Hero Section dari halaman:
https://grafologiindonesia.com/kursus/comprehensive/

## Fitur
- Layout modern satu kolom dengan tema dark + gold
- Animasi intro logo sebelum judul muncul
- Kartu fitur dengan deskripsi yang muncul saat disentuh/hover
- Animasi ripple pada tombol CTA

## Dibuat dengan
HTML , CSS, JavaScript

## Dibantu AI
Sebagian struktur kode dibantu oleh AI terutama dalam animasi CSS (Claude), namun keputusan desain, warnadan alur interaksi ditentukan dan diarahkan sendiri.
